# もち町ものがたり 設計メモ(v0.1.6)

> v3 の設計(街ごとの経済・役人)に、その後の拡張を足した最新の内容です。数値は `src/data.js` が正本です。

## 目的(ユーザー要望)
1. 街ごとの施設が同じメニューの色で見分けがつかない → **街ごとに配色・通貨・施設を分けて見分けがつく**ようにする
2. メニューが高揚感に欠ける → **UIを再設計**(演出・音・紙吹雪・数値のアニメーション)
3. **街ごとにお金とリソースを別管理**にする
4. 元ゲームにあった**自動購入など**を、お金を払って**役人を雇うことで開放**する

## 状態の構造 (v3)
```
st = {
  v: 3,
  t: { [townId]: Town },        // 街ごとの経済(閉じた街は open=false)
  ev: { act, next },            // イベント(全街に影響)
  meta: { fuku, fukuTotal, perks, ach, resets, eventsSeen, playSecTotal,
          goal{clears,best,total}, goal2{...}, homare, reset2, seen{}, mon{} },   // 転生しても残る
  goal: { done, cleared }, goal2: { done, cleared },        // 博覧会 / 大祭の今回の進み(goal2 は転生しても残る)
  stats: { playSec, offlineSec },
  chk, savedAt
}
Town = {
  open,                         // 発見済み(道を切り拓いた)か。本拠地は常に true
  road,                         // 親の街との街道Lv(本拠地は 0 のまま)
  coin, items{}, b{id: {count, progress, level, stalled, why, noAuto}},
  gup{}, res{}, quests{}, autosell{item: keep|null},
  off{ officialId: true },      // 雇った役人
  auto{ build, up, res, gup, road: { on, reserve } },     // 自動化の設定
  ship{ down:{item:{keep,max}}, up:{...} },               // 親↔この街の輸送指示(item='coin' も可)
  stats{ produced{}, received{}, earned, bonus }
}
```
- **お金・資源は街ごと**。街どうしは「輸送」(資源・お金を隣の街へ送る)でつながる。輸送では道のレベルに応じた**ロス率(toll)**で一部が失われる=輸送コスト。
- 輸送は**隣接する街の間だけ**(本拠地—潮見、本拠地—霧ヶ峰、潮見—糸川、霧ヶ峰—大都)。遠い街へは中継(街の在庫が中継点)。
- 街道は親の街のお金で建設・強化。輸送力(個/秒)は道のレベルで決まり、その道を通る両方向の輸送で共有。
- 市場は街ごとに買い取り倍率が違う(例: 潮見は米を2.6倍で買う)。**買い取り以外にコインを得る手段は無い**ので、輸送で「安い街で作って高い街で売る」ことはできても、お金を生み出す裁定は成立しない。

## 街と施設
| 街 | 施設 | 買い取りが高い品 |
|---|---|---|
| もちの里(本拠地) | 田んぼ/水車小屋/餅屋/竹林/製材所/粘土採り/瓦窯/酒蔵/茶畑/釣り堀/茶屋/料理屋 + 工房(漬物屋/鍛冶屋/機織り小屋) | — |
| 潮見(港町) | 漁船/塩田/昆布棚/干物屋/出汁屋 | 米・お餅・お茶・竹板・農具 |
| 霧ヶ峰(山里) | 木こり/鉱山/炭焼き/製鉄所/薬草園/薬湯の宿 | 甘酒・瓦・弁当・魚・餅粉 |
| 糸川(染めの里) | 桑畑/養蚕所/製糸場/藍畑/染物屋 | 茶菓子・お餅・竹板・漬物 |
| 大都(城下) | 金鉱/金箔打ち/金箔工房 | 贅沢品を最高値で |
- 本拠地の工房は、他の街の産物(塩・昆布・鉄・炭・絹糸・染料)を輸送で受け取って使う。
- 通貨も街ごとに別の名前・アイコン(もち銭/貝貨/鉱銭/糸銭/小判)。

## 役人(自動化の開放)
街ごとに、その街のお金で雇う。雇うと機能が開放される。
| 役人 | 開放されるもの |
|---|---|
| 建築奉行 | まとめ買い(×10/最大)+ 自動建築 |
| 普請奉行 | 自動強化 |
| 学者 | 研究の画面 + 自動研究 |
| 蔵奉行 | 町の施設の画面 + 自動購入 |
| 商人頭 | 自動販売の細かい設定(保持数) |
| 飛脚頭 | 輸送指示(自動輸送)と送金 |
| 検地役 | 子の街への街道の自動建設・強化 |
| 祭り奉行 | イベントの頻度・時間アップ |
- 自動化はシミュレーション側(sim.js)で動く。画面を閉じていても/オフラインでも働く。
- 自動建築は「回収が早い順」(コスト ÷ 追加で得られる価値/秒)に、予備金(reserve)を残して買う。

## 効果の集約
`mods(st, townId)`: その街の施設・研究 + 全体の福・パーク・実績 + その街のランク + イベント(全街)。
転生: 全街をリセットし、meta(福・パーク・実績)だけ残す。福は全街の累計獲得額(街ごとの重み付き)から。

## UI 再設計
- 街ごとのテーマ(accent / bg / 通貨アイコン)。タブで街を切り替えると画面全体の色が変わる。
- 上部: 通貨の大きなカウンター(数値が滑らかに増える)+毎秒の収入、街タブ(各街の所持金)、世界地図/町の切り替え。
- 演出: 購入時の紙吹雪・カードのフラッシュ、節目ボーナスのバナー、実績の金色トースト、役人の採用演出、街の発見演出、転生の花火。
- 効果音(WebAudio、ミュート可)。
- ボタンは作り直さず中身だけ書き換える(既存ルール)。

## 町のミニチュア
街ごとにレイアウト(ゾーン)と地面のテーマを持つ。建物の絵は「種類(kind)+配色」で共通化し、固有の絵が無い建物でも描ける。世界地図では街をクリックで切り替え。

## 移行
v2 のセーブ(本拠地だけの経済)は、本拠地に取り込む。旧街道が開通済みの街は open にして開拓資金を与える。

## v0.1.0 までに加えたもの
- **建材**: 建物は、お金のほかに建材(`timber`)が必要。各街の資材場が作る。量は建設費×`MAT.ratio`(保管上限の半分まで)。資材場は建材なしで建てられ、自動建築は建材が足りないときだけ増やす。
- **倉庫と売却**: 自動販売は1品目あたり1秒に `保管上限 × SELL.rate` 個まで。生産は保管上限で止まる(自動販売があっても)。施設「倉庫」は ×1.5/Lv(最大30)。
- **供出**(`TRIBUTE`): 街が3つ以上で、高額な研究・施設に他の地方の特産品(5〜50個)が必要。必要な品は `T.hold` で自動販売・輸送から守る。
- **目標**: 万国もち博覧会(`GOAL`)→ 世代交代(`reset2`。福・パーク・完成回数を手放して誉)→ 天下一もち大祭(`GOAL2`)。完成ボーナスは全体速度。記念碑と開幕特典(`LEGACY`)は転生しても残る。
- **順次開放**(`REVEALS` / `checkReveal`、`meta.seen`): 最初はもちの里だけ。世界地図・分析・目標・福・世代交代・大祭が条件を満たすと現れる。
- **分析**: 品目別の供給・需要の集計(`T.fl`。保存しない)と、画面側の履歴・診断(`sampleHist` / `diagnose`)。
- **絵**: `art.js`(部品)・`sprites.js`・`landmarks.js`・`expo.js`。`town.js` は動かない部分をレイヤーに描いて使い回す。
- **セーブ**: キーは `mochimachi.save`(画面の設定は `mochimachi.ui`)。公開前のセーブは読まない。`normalize` には、構造が古いデータを読み込む移行処理が残っている(テストあり)。
- **軽さ**(`perf.js`): 町・世界地図の描画に使った時間が1秒の12%を超えると、1段ずつ軽くする(最初は20fps・動く絵は5fps)。画面の外では描かない。「⚡ 軽量」で固定。
- **絵のキャッシュ**(`town.js` の `bitmap` / `mini`): 建物・住宅・荷車・住民は、アニメーションの各コマを小さなキャンバスに一度だけ描き、貼って使う(夜の灯りの位置も絵ごとに保存)。街の切り替え・軽さのレベル変更で捨てる。
- **タイムトークン**(`TIMETOKEN`、`meta.bank`): `applyOffline` が、上限を超えた離席時間+上限以内の `share` を貯める。加速は画面側(`UI.boost`)で、`frame()` が加速で増えた時間ぶんだけ `bank` を減らす(シミュレーション自体は変えない)。
- **手元に残す数**(`T.keep`): 自動販売のオン・オフと独立に持ち、自動販売と手動の「売る」の両方に効く(「全部売る」は無視)。
- **加工の値上がり**: 材料のある工房は、出来た物の値段が材料の合計より10%以上高い(基準の値段でも、その街の買い取り倍率を入れても)。`tests/body.js` が全工房を検査する。
