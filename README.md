# もち町ものがたり

小さな田んぼから始めて、お餅の里を世界一の町に育てる**放置系の町づくりゲーム**です。ブラウザだけで動き(インストール不要)、閉じている間も町は働き続けます。

- 遊ぶ: https://uruurus15.github.io/mochimachi-monogatari/
- バージョン: **v0.1.1**
- 想定クリア時間(目安): 万国もち博覧会の完成まで **約10時間** / 天下一もち大祭まで全部クリアするまで **約30時間**(放置・オフライン含む)
- 保存はブラウザの中(localStorage)だけで、サーバーには何も送りません。

> 放置系ゲームの一般的な構造を参考にした**完全オリジナル**の作品です。コード・絵・数値・テーマはすべて新規で、他のゲームのデータや素材は含みません(特定のゲームとは無関係の非公式の作品です)。

## 遊び方

1. **田んぼ**を建てて米を作り、売ってお金にします。お金が貯まったら、水車小屋 → 餅屋 …と、材料を使う建物を増やして生産のつながりを伸ばします。
2. 建物には、お金のほかに**建材**が要ります。建材は**資材場**で作ります。
3. お金が貯まったら**役人を雇い**ます。まとめ買い・自動建築・自動強化・研究・自動輸送などが開放され、放置でも町が育ちます。
4. 累計の稼ぎが増えると、**新しい街への道**が切り拓けます。街ごとに特産品・通貨・施設・買い取り価格が違い、街どうしは**輸送**でつながります。
5. 5つの街に館を建てて**万国もち博覧会**を開くのが最初の目標です。完成すると、その先の遊びが開けていきます。

最初は「もちの里」しか見えません。条件を満たすと、世界地図・目標・福・世代交代…が順番に現れます(「新しい発見!」の演出つき)。

## 主なしくみ

| しくみ | 内容 |
|---|---|
| 5つの街 | もちの里 / 潮見(港町) / 霧ヶ峰(山里) / 糸川(染めの里) / 大都(城下)。街ごとに通貨・在庫・施設・研究・クエスト・役人・配色が別 |
| 道と輸送 | 道を切り拓くと街が見つかる。道のレベルで輸送力が増え、ロスが減る。お金は市場での売却だけで増える(輸送では増えない) |
| 役人 | 商人頭・建築奉行・普請奉行・学者・蔵奉行・飛脚頭・検地役・祭り奉行。雇うと機能が開放され、自動化は閉じていても働く |
| 建材 | どの建物も、お金のほかに建材が必要。資材場の作りやすさは街しだい |
| 倉庫と売却 | 自動販売は1秒に「保管上限 × 0.5」個まで。作りすぎると倉庫が満杯になって止まる。施設の「倉庫」で上限と売る速さが伸びる |
| 供出 | 街が3つ以上になると、高額な研究・施設に**他の地方の特産品**が必要になる(輸送を使いこなす) |
| 万国もち博覧会 | 5つの街の館+開会式。世界地図に会場と館が建つ。完成するたびに全体速度アップ |
| お祭り(転生) | 全街をまっさらにして**福**を得る。福のパークで強化。記念碑・開幕特典(最初から役人)も残る |
| 世代交代 | 博覧会を2回完成させると開放。福・パークを手放して**誉**(大きな全体速度アップ)を得る |
| 天下一もち大祭 | 誉があると挑める、その先の最終目標。館(殿)は転生しても残る |
| 分析 | 街ごとに、品目別の在庫・供給・需要・収支のグラフと、直し方つきの診断が見られる |
| 画面 | 街ごとに別のミニチュアの町(昼夜つき)と世界地図。演出・効果音(右上でミュート) |

## 想定クリア時間(目安)
| 目標 | 時間 |
|---|---|
| 万国もち博覧会を初めて完成させる | 約10時間 |
| 2回目の博覧会 → 世代交代 | 約20時間 |
| 天下一もち大祭まで全部クリア | 約30時間 |

ボットが最適に近く遊んだ計測では、博覧会の1周目が約8時間、2周目が約4時間、全クリアが通算約26時間でした。人が遊ぶと寄り道が入るので、区切りのよい時間で書いています。オフラインでも進みます(上限は施設・研究・パークで伸びる)。

## 開発者向け

ビルド不要の素の HTML / JavaScript / Canvas です。`index.html` をブラウザで開けば動きます(GitHub Pages でもそのまま動く)。

```
index.html      通常版(ここから遊ぶ)
debug.html      デバッグ版(時間加速・スキップ・各システムの操作パネル。セーブは別枠)
src/data.js     すべてのデータ(品目・街・施設・役人・研究・パーク・目標・実績・調整値)。内容を増やすときはここ
src/sim.js      シミュレーション(画面に依存しない。Node でテストできる)
src/ui.js       画面と入力。ボタンは作り直さず、変わった部分だけ書き換える(高速でもクリックが落ちない)
src/art.js      描画部品(輪郭・陰影・瓦・光源)
src/sprites.js  施設の絵
src/landmarks.js 役所・交易所・噴水・天守・荷車
src/expo.js     博覧会・大祭の絵(世界地図用)
src/town.js     街のミニチュア(レイヤーで軽量化)
src/world.js    世界地図
src/fx.js       紙吹雪・バナー・効果音
src/debug.js    デバッグ版の操作パネル
tests/bot.js    進行テスト(node tests/bot.js。約3分。本体は tests/body.js)
tools/gallery.html  絵の一覧(?night=0.5 で夜)
docs/DESIGN.md  設計メモ
```

- **進行テスト**: `node tests/bot.js` は、役人の自動化を使うボットで長時間プレイをシミュレートし、数値の健全性・解放の早さ・会計・輸送の裁定・刻み幅の等価性・転生・世代交代・旧セーブの移行などを検証します(乱数は固定)。
- **街・施設を増やすとき**: `data.js` の `TOWNS` / `BUILDINGS` / `ITEMS` に足し、`town.js` の `MAPS` に配置を足します(研究・クエスト・実績は自動で付きます)。
